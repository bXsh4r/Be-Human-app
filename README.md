# Why make this app?

In today's age of distraction we tend to waste alot of our time. We might be having an activity in mind. Something to do when we are free like reading a book or going out for a walk. But when the time comes, when we are finally free. We procrastinate, we find excuses. If only there was something that can motivate us, make us stand up throw the distraction away, and do the activity we've been thinking about. This is where this app comes in. 

# What does this app do?

This app allows you to schedule your activity (e.g. reading a book) for a specific time period and day. when the time comes the app will send you a notification telling you that it's time to get up. You'll be prompted to start a timer. which will start counting the time period you have set (e.g. 8 PM - 9 PM = 1 hour timer). this will make you go and start doing the activity you wanted to do until the timer ends. You can delay the timer but there isn't an option to cancel. 
At the end of the day it depends on how much the user is willing to actually fix himself and kill the distractions.
